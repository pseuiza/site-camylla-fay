# Camylla Fay — Arquitetura & Interiores

Site responsivo em HTML, CSS e JavaScript puro.

## Identidade visual
Paleta quente inspirada na referência da cliente: off-white, areia, dourado champagne, taupe e madeira/nogueira.

## Publicação na Vercel
Importe o repositório GitHub na Vercel. Use Framework Preset `Other`, Build Command em branco e Output Directory `.`.
